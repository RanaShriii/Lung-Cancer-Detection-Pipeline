# Lung Cancer Risk Prediction using Machine Learning

This project focuses on early lung cancer risk prediction using structured clinical survey data. The project involves data preprocessing, exploratory data analysis, feature engineering, statistical analysis, and comparative evaluation of multiple machine learning models.

The objective of this work is to develop an efficient and reliable machine learning pipeline for healthcare-oriented risk prediction.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Comparative machine learning model evaluation
- Performance analysis using classification metrics
- End-to-end ML workflow implementation

## Technologies Used
- Python
- NumPy
- pandas
- scikit-learn
- TensorFlow
- Matplotlib

## Research Contribution
This work contributed to the research paper:

**“Machine Learning Framework for Early Lung Cancer Risk Prediction Using Patient-Reported Clinical Data”**  
Presented at MPCON 2026.
